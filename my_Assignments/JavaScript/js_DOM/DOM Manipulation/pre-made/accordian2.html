Accordion Menu

Accessible accordion with keyboard support, smooth animations, and single/multi-open option.

Welcome! This is the first panel. Put any content you like here: paragraphs, lists, images, forms, etc.

Features include: keyboard navigation, ARIA attributes, smooth height animation, and the option to restrict to a single open panel.

Example code can be placed here. The panels animate with a CSS transition of max-height; the script sets the computed scrollHeight to allow smooth expansion.

Tip: add or remove data-single on the .accordion element to switch between single-open and multi-open behavior.
